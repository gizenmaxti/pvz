# PVZ Remake (植物大战僵尸复刻)

> 基于 C++17 和 EasyX 从零独立开发的 2D 塔防游戏原型。  
> 项目重点不在于“复刻”，而在于**从零搭建可扩展的游戏框架**。

---

## 🎮 项目简介

这是一个使用 C++ 和 EasyX 图形库开发的植物大战僵尸同人 Demo。  
项目实现了主菜单、关卡选择、植物选卡、种植、冷却、动画播放等核心流程。

核心战斗仍在开发中拓展中。

---

## 🧱 核心架构

- **场景管理**：`Scene` 基类 + `SceneManager` 单例 + `std::stack<std::unique_ptr<Scene>>`
- **数据驱动**：植物数据通过 `plant_registry` 注册表统一管理
- **模板与实例分离**：`plantinfo` 存静态数据，`plant` 存战斗实例状态
- **时间点冷却**：使用 `std::chrono::steady_clock` 实现帧率无关冷却
- **智能指针**：场景对象由 `std::unique_ptr` 管理生命周期
- **UI 解耦**：按钮行为通过 `std::function` 工厂函数注入

## 🖥 运行方式

1. 使用 Visual Studio 2022 打开 `.sln` 文件
2. 确认 C++ 标准为 C++17
3. 编译运行

> 注意：项目依赖 EasyX 图形库，请先安装 EasyX。

## 🔥 项目亮点

- 从零手写游戏框架，未参考现成开源框架
- 严格区分对象所有权：拥有用 `unique_ptr`，借用用裸指针
- 使用 `std::optional` 表达“格子是否有植物”
- 冷却系统使用真实时间点，避免帧率波动
